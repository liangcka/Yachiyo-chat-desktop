# 桌面使用指南

Yachiyo Chat Desktop 面向 Tauri 桌面窗口与 PC 浏览器。当前版本统一使用桌面布局，不包含独立移动版界面，也不显示右下角看板娘。

## 启动与配置

- 原生桌面开发：`npm run desktop:dev`。
- 浏览器本地体验：`npm run dev:mock`，打开控制台给出的地址即可。开发环境使用 `yachiyo-local-access` 自动建立会话。
- 首次打开桌面端时，欢迎页会显示“先连接一个模型”。点击“配置模型”（或左下角“设置 → 模型”），填写任一供应商的个人 API Key 并选择模型即可开始对话。Mock 模式使用本地模拟回复，不验证真实模型服务能力。
- 桌面端的 API Key 只保存在本地网关：Windows 下用系统 DPAPI 按当前登录用户加密，界面与本地数据库只记录“已保存”状态。编辑已有配置时 Key 留空即沿用原值。
- PC 浏览器需要 Pages Functions；原生桌面使用本机 Rust 网关，前端通过 IPC 获取网关实际端口后直连。连接失败时先检查对应后端是否运行。
- 桌面端启动时会检查 GitHub 上的最新正式版，发现新版本时在右下角提示，点击“前往下载”打开发布页。也可以在“设置 → 应用”中手动检查。

## 界面与会话

左侧管理新建、搜索、置顶和重命名会话，左下角提供用户资料与设置。中间顶部切换对话和编辑器；“成果审阅”展开右侧代码审阅、代码预览、成果工件与工作区。

空白会话在中间显示欢迎内容与输入框。首次发送后，输入框平滑下移到底部，消息在上方显示。输入框保持同一个节点，焦点和多行输入状态不会因位置改变而丢失。后续发送和流式文字更新不重复播放下移动画。

- `Enter`：发送消息。
- `Shift+Enter`：输入换行。
- 中文 / 日文输入法仍在选词时，`Enter` 只确认选词。
- `+`：添加图片；是否可用取决于当前模型的图片能力。
- `/`：快捷指令与技能菜单；使用方向键选择、`Enter` 确认、`Esc` 关闭。
- `@`：在已选择的工作区中搜索并引用文件。
- 生成过程中可点击停止；请求失败时保留现有错误提示和重试入口。

## 工作区与权限

在输入框上方选择项目。原生桌面可关联本地目录，并使用编辑器、文件树、终端与 Git 审阅。文件修改和命令执行遵循现有工作区权限审批；PC 浏览器界面不会自行获得本机工具能力。

## 桌面快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+N` | 新建对话 |
| `Ctrl+1` / `Ctrl+2` | 对话 / 编辑器切换 |
| `Ctrl+[` | 折叠或展开侧栏 |
| `Ctrl+B` | 展开或收起成果面板 |

macOS 上也可使用对应的 Command 键。窗口变窄时，成果面板覆盖中栏，可通过关闭按钮或快捷键返回对话。

## 外观与动态效果

在设置的“外观与语言”中切换深浅主题和中日语言，原有主题色保持一致。欢迎内容使用轻量淡入，话题箭头提供轻微悬停反馈；首次发送时使用约 250ms 的输入区位置过渡。

动画跟随系统的“减少动态效果”偏好：关闭输入区位移与箭头移动，仅保留短暂淡入。窗口尺寸变化或切换会话时，正在执行的位置过渡会取消，避免输入区偏离布局。

## 保留的历史文件

`android/`、`capacitor.config.ts`、移动端构建脚本及历史截图仍保留，但当前版本不提供独立移动 UI。历史架构与性能记录继续保留，当前入口以本指南和 [运行时与隔离边界](ARCHITECTURE_ISOLATION.md) 为准。
