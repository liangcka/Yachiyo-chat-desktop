# Agent Note: 桌面输入工具栏布局演进、执行模式文案重构与可勾选联网菜单

Status: implemented

## Problem

在桌面端（对标 Codex 桌面版、Antigravity 与 Claude 桌面版）对话输入区（`DesktopChatArea`）中，存在以下几处布局与交互体验的不协调：
1. **执行模式选项文案歧义与可见性不足**：原执行模式选项文案为“只读 / 需确认 / 全自动”，其中“需确认”与“全自动”在现代化智能体桌面端不够凝练直观，且工具栏按钮文字固定为“模式”，无法直接在未点开下拉前感知当前状态；
2. **工具栏空间挤占与功能归类混乱**：原工具栏左侧包含加号按钮、模式选择与常驻的“联网”切换开关，右侧包含模型选择、上下文用量指示与发送按钮。联网开关常驻占用横向空间，且与文件/项目/技能添加操作割裂；模型选择器放在右侧导致左侧与右侧的智能体基础设置割裂；
3. **输入框卡片视觉质感偏重**：卡片在焦点状态下缺乏平铺中性灰阶规范定义的精准焦点加深反馈，存在多余阴影或非设计变量的颜色；
4. **ContextMeter 颜色硬编码**：环形进度与色块存在未走 tokens.css 的直接色值声明，缺乏中日双语国际化感知。

## Decision

- **执行模式文案重构为“只读 / 自动 / 完全访问”**：
  - 选项对外显示文案更名为“只读”、“自动”、“完全访问”（日文环境下分别映射为“読み取り”、“自動”、“完全アクセス”）；
  - 内部取值保持显式契约 `readonly` / `confirm` / `full_auto` 100% 不变；
  - 工具栏 pill 标签与 title 同步呈现当前选中的模式名称，并将 `.desktop-mode-select` 宽度改造为弹性自适应；
  - 快捷指令 `/agent` 的描述文案与切换 Toast 提示同步更新。
- **联网开关移入 + 菜单，做成可勾选菜单项**：
  - 从工具栏顶层移除独立的联网按钮；
  - 在加号弹出菜单（`dsh-add-menu`）中加入带复选框的勾选菜单项（`<Globe /> 联网搜索`），状态与 `webSearchSettings.enabled` 双向绑定；
  - 点击菜单项可直接勾选或反选，保持即时反馈与无障碍语义（`role="menuitemcheckbox"` 与 `aria-checked`）。
- **工具栏左/右布局严格对齐 Codex / Antigravity 桌面版标准**：
  - **左侧容器**依次放置：
    1. `+` 添加内容菜单（内含文件/图片、工作区项目、技能加载及联网搜索勾选开关）；
    2. `ModelSelect` 模型选择器（菜单改为向左对齐 `left: 0; right: auto`，防止左侧贴边截断）；
    3. `desktop-mode-select` 执行模式选择器。
  - **右侧容器**依次放置：
    1. `ContextMeter` 上下文用量指示器（支持 `locale` 双语，未过半时隐藏特性严格保留）；
    2. 发送/停止复合按钮。
- **输入框卡片极简平铺设计与深浅两套主题适配**：
  - 卡片具有 1px 边框、8px 圆角、无阴影；
  - 聚焦时边框变深：通过 `tokens.css` 引入 `--composer-border-focus`（深色模式 `rgba(255, 255, 255, 0.24)`，浅色模式 `rgba(0, 0, 0, 0.24)`）；
  - 全量适配系统 `@media (prefers-reduced-motion: reduce)`，关闭过渡与动画。
  - `ContextMeter` 移除硬编码色值，使用 `--context-meter-system`、`--context-meter-tools`、`--context-meter-messages` 等中性主题变量。

## Alternatives considered

- 将联网开关保留在工具栏右侧：导致横向宽度在窄容器（例如侧栏展开或分屏状态）下过早折行；收纳至 `+` 菜单符合现代工具将能力注入（技能/文件/上下文/网络）集中的心智模型。
- 模式按钮仍显示“模式”二字：无法在工具栏一眼确认当前执行模式是否处于全自动或只读风险态；直接显示当前选中模式极大提升了信息密度与操作透明度。

## Consequences

- 工具栏操作逻辑层次分明：左侧负责环境配置（上下文输入源、驱动模型、执行权限），右侧负责资源监控与运行指令（上下文用量、发送）；
- 输入框卡片更加紧凑专业，视觉风格完全融入灰阶平铺体系；
- 既有状态逻辑、快捷键、国际化与单元测试完全兼容通过。
