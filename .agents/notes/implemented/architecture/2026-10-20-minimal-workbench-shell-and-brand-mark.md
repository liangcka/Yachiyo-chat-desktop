# Agent Note: 精简工作台外壳与单色品牌标识

Status: implemented

## Problem

桌面外壳的顶栏、侧栏与欢迎页信息层级偏重：顶栏带彩色徽章与应用名并有分隔线，侧栏同时放项目下拉、搜索框、按时间分组的历史和用户卡片，欢迎页有头像、问候语与四张快捷卡片。界面视觉重心分散，输入框不是空白对话的唯一焦点；品牌图标含底圆与两颗星，小尺寸下难以辨认。

## Decision

- 品牌标识简化为月牙加一颗小星。界面内用 `BrandMark` 组件以 `currentColor` 渲染单色字形；应用图标、PWA 图标与 favicon 统一为深色圆角底上的白色字形，`src-tauri/icons` 下的 Android/iOS 子目录保持不变。
- 顶栏与正文同色、无分隔线，左侧依次为品牌按钮、侧栏开关、搜索按钮。搜索按钮打开现有命令面板（Ctrl+K），由命令面板承担会话检索，侧栏不再放搜索框。
- 侧栏结构为：新建对话、项目、对话、底部设置行。
  - 项目区列出最近项目：点击即切换工作区并新建对话，当前项目提供"打开文件与终端"和"关闭项目"。
  - 对话区为扁平列表，置顶会话在前，条目右侧显示紧凑相对时间（`5m`、`3h`、`2天`，超过 30 天显示月/日）；悬停时操作按钮占据时间的位置。
  - 底部设置行直接打开设置，右侧头像打开原有用户菜单。
- 空白对话只保留输入框，以及其上方的项目选择器；模型未配置时仍显示配置引导。输入框占位文案提示 `@` 引用文件与 `/` 执行动作。
- 阅读列与输入框宽度收窄到 680px，桌面正文 14px。
- 圆角统一放大：输入框与用户气泡 18px，列表条目 9px，图标按钮、新建对话按钮与工具栏胶囊为全圆。

## Alternatives considered

- 会话按项目归属分组：需要给会话增加项目字段并迁移存量数据，不在本次范围内。
- 保留时间分组标题：与扁平列表加相对时间的信息重复。

## Consequences

时间分组的折叠状态（`yachiyo-sidebar-collapsed-groups`）不再读取，旧值留在 localStorage 中无副作用。欢迎页快捷卡片及其提示词被移除。会话尚未记录所属项目，项目区只负责切换工作区。
