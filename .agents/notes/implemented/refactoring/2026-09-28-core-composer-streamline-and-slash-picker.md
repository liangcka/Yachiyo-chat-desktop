# 核心输入区精简与快捷指令分层架构

## 1. 决策背景与架构动机

在月见八千代向专业生产力与智能体工作台（Agent Studio）演进的过程中，中间核心执行区的交互层级面临以下瓶颈：

1. **输入框功能过度承载**：旧版底部输入框工具条堆叠了模型选择下拉、Agent 模式开关、技能配置 Popover、联网搜索状态等多个重型控制部件，导致核心输入卡片视觉杂乱，干扰纯文本与多模态创作的沉浸感。
2. **快捷唤醒机制缺失**：用户需要频繁切换鼠标点击技能与 Agent 设置，缺乏现代 AI IDE（如 Codex、Antigravity）中通过 `/` 和 `@` 进行键盘驱动的指令与上下文分层调用能力。
3. **顶栏状态与高级控制分离**：顶栏右侧存在大量未被充分利用的水平空间，而长对话滚动时底部输入框的高级状态无法直观驻留于视口中。

因此，实施**阶段一：中间执行区精简与快捷指令分层**架构改造。

---

## 2. 核心架构变更

### 2.1 高级设置外提至顶栏 (`desktop-chat-header__actions`)
- 将 `ModelSelect`（模型选择器）、`Agent 模式` 切换胶囊、`技能快捷配置` 浮层触发器与 `联网搜索` 切换按钮统一上提至中间执行区的顶栏右侧。
- 这一改动实现了视口全局状态常驻，使得长列表滚动浏览时用户对当前模型、Agent 模式及联网状态的感知保持稳定。
- **浮动定位与视觉修正**：由于触发器从底部迁移至视口顶栏，将 `.dsh-skill-popover` 定位由原先的底部上弹（`bottom: calc(100% + 8px)`）调整为**顶部下弹且右对齐**（`top: calc(100% + 8px); right: 0; transform-origin: top right;`），彻底解决点击技能时弹窗超出屏幕上方视口边界的问题。
- **胶囊样式一致性**：引入统一的 `.desktop-header-pill` 风格，在浅色与深色主题下提供柔和半透明背景与低饱和主题蓝高亮，消除默认焦点外框与视觉割裂。

### 2.2 输入框极简瘦身 (`dsh-composer-card`)
- 底部工具栏清退冗余的高级设置部件，收敛为两个基础操作按钮：
  - `+`：多模态图片/附件上传；
  - `/`：快捷指令与技能唤起按钮。
- 右侧仅保留紧凑型 `ContextMeter`（上下文用量指示器）以及 34px 发送/停止圆形按钮。

### 2.3 快捷指令系统 (`SlashCommandPicker`)
- 新增 `SlashCommandPicker` 模块（位于 `src/components/chat/SlashCommandPicker.tsx`），与已有的工作区文件引用选择器（`FileReferencePicker`）在架构上保持一致性。
- **触发机制**：在输入框内键入 `/` 或点击工具栏 `/` 按钮，即刻唤起快捷指令面板。
- **支持条目**：
  - **内置技能（Skills）**：遍历 `SKILLS` 列表，实时模糊过滤并支持一键加载/卸载技能扩展；
  - **系统动作（Actions）**：支持快速切换 Agent 运行模式（`/agent`）、切换联网搜索（`/web`）、新建对话（`/clear`）。
- **键盘导航**：深度集成 `ArrowUp`、`ArrowDown`、`Enter`、`Tab` 与 `Escape`，并提供实时字符高亮与完整 WAI-ARIA 无障碍支持。
