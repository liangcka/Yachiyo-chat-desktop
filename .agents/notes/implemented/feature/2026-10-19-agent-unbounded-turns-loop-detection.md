# Agent Note: Agent 轮次不设上限，改由循环检测叫停

Status: implemented

## Problem

桌面端每次对话都走 Agent 循环，循环固定最多 12 轮（`AgentLoopConfig::max_turns` 默认 12，前端不传 `maxTurns`）。读多个文件、改多处代码这类正常的长任务会在第 12 轮被硬截断，前端只显示“回复太长，已截断显示”，与真实原因不符。

固定上限防不住真正的失控：模型反复执行同一个工具调用、看到同样的结果，或者在思考里复读同一段话，12 轮之内照样会消耗大量 token。DeepSeek Agent 的单次输出预算是 256K，复读能在一轮之内把它耗完。

## Decision

### 轮次

`AgentLoopConfig::max_turns` 改为 `Option<u32>`，默认 `None` 表示不限。客户端仍可通过 `agent.maxTurns` 显式设上限，超出时照旧返回 `MaxTurnsReached`（`done.truncated = true`）。

### 工具循环（`gateway/agent/loop_guard.rs::ToolLoopDetector`）

每轮工具执行完后记录两种签名：调用加结果（工具名、参数、回填给模型的输出），以及只有调用。签名序列末尾出现周期为 1～3 轮的完整重复时判定为循环：

- 调用与结果都相同，重复 3 个周期即触发。模型看到的信息没有变化，再重复也不会有新进展。
- 只有调用相同、结果在变（例如轮询构建状态），放宽到 5 个周期。

第一次触发时，在该轮最后一条工具结果末尾追加 `[循环提醒]`，要求模型换方法或向用户说明卡住的原因，同时清空计数。提醒之后再次触发才结束运行。提醒附在工具结果里而不是另起一条用户消息，Anthropic、Gemini、Responses 等协议的消息交替约束都不受影响。

### 输出复读（`RepetitionDetector`）

`HttpTurnExecutor` 对思考流和正文流各维护一个检测器，保留最近 16KB，每新增 256 字节检查一次，满足任一规则即判定为复读：

- 样本规则：取末尾 80 字节作样本，在窗口内不重叠出现 8 次以上。样本少于 10 种不同字符时跳过，排除分隔线、表格线等天然重复的排版。
- 周期规则：窗口末尾 4096 字节以不超过 64 字节的周期严格重复。覆盖“好的好的好的…”这类不同字符很少、被样本规则跳过的短周期复读，而正常文本不会出现数千字节的严格周期。

触发后丢弃响应流（断开上游连接、停止计费），执行器返回 `REPETITION_LOOP_DETECTED` 标记，循环据此结束而不是按上游故障处理。

### 流保活

去掉轮次上限后，单次运行可以持续很久，而客户端对流有 45 秒的空闲超时。原来只有等待授权时才下发心跳，工具执行（`cargo build`、测试）或上游长时间不输出时整条流静默，会被客户端误判为断流。`run_agent_chat_stream` 改为常驻 5 秒周期的 SSE 注释心跳，已排队的事件优先于心跳下发。

### 结束契约

新增 `LoopOutcome::LoopDetected`。SSE `done` 事件增加可选字段 `reason`，循环叫停时为 `"loop_detected"`，`truncated` 为 false。前端 `StreamChatResult.stopReason` 读取该字段，消息记为 `loopStopped: true`，气泡下方显示“检测到重复循环，已自动停止”。叫停时即使没有正文，已经执行的工具步骤也有价值，因此按完成落盘而不是判为失败。

## Alternatives considered

- **只把上限调大（例如 50 轮）**：仍会截断正常的长任务，也照样防不住 50 轮之内的空转。
- **检测到循环立即停止，不先提醒**：模型常常只需要一次提示就会换路线；先提醒一次可以挽回大部分情况。
- **另起一条用户消息作为提醒**：各家协议对工具结果之后紧跟用户消息的处理方式不一，附在工具结果里不改变消息结构，最稳妥。
- **按调用名计数（同一工具调用 N 次即叫停）**：反复读取同一文件在改动之后是正常行为；以“调用加结果”是否变化作为进展依据更准确。
- **对每个字符做滑动窗口哈希的复读检测**：精度更高但实现复杂；退化复读通常是整句整段的原样重复，定期抽样末尾片段已经足够。

## Consequences

- 长任务不再被 12 轮截断，运行由模型自行结束、用户手动停止或循环检测叫停。
- 没有进展的工具循环最多多跑 3 轮（提醒后）即停止；整句复读在大约 640 字节内被截断，短周期复读在 4KB 内被截断。
- 结果持续变化、调用路线也在变化的长时间运行不会被叫停，只能由用户手动停止。
- `done.reason` 是新增可选字段，旧版前端会忽略它，行为退化为普通完成。
